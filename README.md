# E-Commerce Marketplace

A full-stack e-commerce marketplace built with **Next.js, TypeScript, and PostgreSQL**. This project focuses on building a modern shopping experience with customer authentication, product browsing, and persistent shopping carts.

## Features

- **Product Catalog:** Browse products retrieved from the [DummyJSON Products API](https://dummyjson.com/docs/products).
- **Product Details:** View individual products and their information.
- **User Authentication:** Register and log in using email and password with Better Auth.
- **Shopping Cart:** Add products, update quantities, and remove items.
- **Persistent Shopping Carts:** Store authenticated customers' carts in Neon PostgreSQL.
- **Guest Shopping:** Allow visitors to use a shopping cart without signing in.
- **Responsive Design:** Browse the marketplace on different screen sizes.
